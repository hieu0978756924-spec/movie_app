## Tech Stack

- **Flutter** + **BLoC** (state management)
- **Supabase** (auth, database, storage)
- **TMDB API** (movie data)
- **GoRouter** (navigation)
- **Hive** (offline cache)
- **get_it + injectable** (dependency injection)
